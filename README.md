# CryptoPulse - SaaS Landing Page

CryptoPulse is a crypto market dashboard that fetches live cryptocurrency data and displays it in a clean, dark-themed interface — including top gainers, top losers, and a searchable market table

## 🛠️ Tech Stack

- React 19
- Vite
- React Bootstrap
- React Icons

## 📁 Project Structure

```
src/
├── components/
│ Crypto/
│   │       ├── navbar.jsx      # Top navigation bar
│   │       ├── sidebar.jsx     # Left sidebar navigation
│   │       ├── cards.jsx       # Hero section + stat cards
│   │       ├── header.jsx      # Top Gainers/Losers + live market table
│   │       └── footer.jsx
├── App.jsx
├── main.jsx
└── index.css
```

## Features

- Fully responsive — Mobile, Tablet, Desktop
- Dark theme design
- Component-based architecture
- Live data from CoinGecko API
- Loading & error states
- Search / filter functionality

## Run Locally

```bash
npm install
npm run dev
```
